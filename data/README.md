# Data and model references

Use [artifacts.csv](artifacts.csv) for externally stored datasets, model weights and captures. Record version, stable location, checksum, license and the code/configuration that uses the artifact.

Small, redistributable deterministic test fixtures may be committed in a clearly named fixtures/ subfolder. Large downloads belong in ignored [raw/](raw/README.md) or [models/](models/README.md). The initial manifest contains headers only.
