# Project management

Store the current proposal, schedule, design-review decks, approved exports and team decisions here. Git history replaces piles of duplicate revision copies.

[owners.csv](owners.csv) records the previously discussed subsystem responsibilities. GitHub identities and review assignments remain unverified. Verify them before adding active CODEOWNERS entries or changing repository access.

Use GitHub Issues for tasks and defects. A lightweight project board can use Backlog, Ready, In progress, Review and Done. Use milestones for demonstrated integration gates rather than creating releases that imply untested vehicle capability.
