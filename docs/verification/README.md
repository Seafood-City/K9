# Verification and evidence

Keep test definitions under [plans/](plans/README.md), execution records under [records/](records/TEMPLATE.md), and selected evidence plus its [index](evidence/index.csv) under evidence/.

Preserve the existing integration IDs, including IT-01, IT-02, IT-03 and IT-07 and their defined subtests. The current source plan determines the meaning of every ID.

A completed record identifies the tested source commit, hardware, firmware, parameter file, procedure revision, expected result, observed result, operator and evidence. Mark PASS, FAIL, BLOCKED or NOT RUN based on the actual execution. A configuration screen or a successful CI run alone is not proof of physical actuation or autonomous operation.
