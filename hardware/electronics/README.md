# Electronics and Altium

Store Altium project, schematic, PCB and required library source here. Preserve linked design dependencies when moving an existing project.

Suggested schematic sheets are system interconnect, power and stopping, Pixhawk drive interfaces, and Jetson/sensor interfaces. Record connector orientation, voltage, signal ground, measured rail voltage and actual receiver/ESC/servo models.

Binary design files should have one active editor at a time. Review schematic/PCB exports alongside source changes because Git cannot meaningfully merge them. Do not use the ignored Altium generated-output folders as the only location of an approved deliverable.
