# Optional ROS 2 workspace source

Place team ROS 2 packages here only if ROS 2 is adopted. Record the chosen distribution and compatible device stack before installing dependencies.

Keep package.xml, build metadata, launch files and package-specific resources with each package. Colcon build/, install/ and log/ directories remain ignored.

Do not duplicate the same package under software/src/ and this workspace; choose one owner/location and document any dependency relationship.
